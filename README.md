# Liquid Glass Calculator

A stunning, modern, glassmorphism-style calculator web application featuring dynamic themes, smooth interactions, 3D tilt effects, calculation history, and delightful acoustic feedback.

## Features
- **Liquid Glassmorphism UI**: Beautiful translucent design with dynamic background orbs and adjustable themes (Aurora, Midnight, Sunset, Light Frost).
- **Interactive 3D Tilt**: Powered by vanilla-tilt.js for immersive card movement.
- **Calculation History**: Slide-out panel to view, reuse, or clear past calculations.
- **Audio & Visual Feedback**: Optional click sounds and responsive button animations.
- **Responsive Layout**: Works seamlessly across desktop and mobile browsers.

## How to Run
Simply open `index.html` in any modern web browser! No installation or build steps required.
